# engine — родове ядро фабрики (у роботі)

Тут житиме спільний код, незалежний від домену: схема `sources.json`, білий список джерел, реєстр читачів
(`readers/`), збірка корпусу й заливка у векторну базу. Зараз порожньо: код ще живе всередині
`instances/ecmascript/` (теки `common/` і `challenges/`). У фазах 2-3 спільне витягується сюди, а доменне
(читачі й записи джерел) лишається в примірнику.

Загальний опис і фази — у [../README.md](../README.md).
