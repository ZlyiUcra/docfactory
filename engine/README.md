# engine — родове ядро фабрики

Спільний код, незалежний від домену. Що тут лежить:

- `sources.py` — схема `sources.json` і білий список: дозвіл рахується з оголошення, шляхи порівнюються
  нормалізованими;
- `net.py` — єдиний мережевий шлюз: кожне звернення і кожен перехід редиректу проходять той самий білий список;
- `readers/` — реєстр читачів (`toc`, `page`, `rfc`, `report`, `ldml`, `pdf`); новий домен додає своїх через
  `@register("ім'я")`, ядро не змінюється;
- `refresh.py` — оновлювач корпусу: тягне лише задеклароване, пише атомарно через тимчасовий файл;
- `status.py` — звірка «що змінилося нагорі»: нове, змінене, сироти і «невідомо» для джерел, які не відповіли;
- `manifest.py` — паспорт корпусу `corpus/index.json`: суми тексту, якими звірка відрізняє «змінилося» від
  «те саме».

Запускається кроками `./df <домен> …` з кореня фабрики; дані домену код бере зі змінної `DF_INSTANCE_DIR`
(її виставляє `df`), а не з розташування самого коду. Доменне — записи джерел і корпус — живе в
`instances/<домен>/`.

Загальний устрій — у [../README.md](../README.md), проведення апдейту корпусу — в [../UPDATE.md](../UPDATE.md).
