# server — спільний MCP-сервер фабрики

Тут лежить увесь код сервера, спільний на всі домени: `spec_mcp.py` (сам MCP-сервер із двома інструментами,
на stdio й на HTTP), `agent.py` (власний захищений агент, Mode A), `layers.py` (чотири шари захисту),
`setup.py` (заливка векторів), `smoke.py`/`check.py`/`raw.py`/`quality.py` (перевірки). Пошук по словах і за
змістом — поруч, у `../common/`.

Код не лежить усередині жодного домену, тож із яким саме доменом він працює, йому кажуть ззовні: `df` перед
кожним кроком виставляє `DF_INSTANCE_DIR` на теку `instances/<домен>/`, і звідти беруться `corpus/`, `.env`,
`out/`, `config.json`. Новий домен цей код не копіює — додає лише свою теку даних.

Загальний опис і фази — у [../README.md](../README.md).
